# 飞机持续跟踪

按注册号创建飞机实体；实时 feed 合并查询启用注册号，同一周期共享完整原始批次（最长 600 秒），每个目标仍按注册号唯一匹配，可核对 ICAO24。对当前 flight ID 分散获取航班详情和来源分类；身份、班号、起降机场一致后合并。近期记录已包含有效详情时不重复请求 clickhandler。每次换航班都单独计算状态，避免沿用上一班的延误。

实时 feed 无坐标时查询注册号历史，优先匹配正在执行/近期待飞/最近结束的航班，核对时间和飞机身份。明确的已降落、未起飞可独立显示，地图保留最后位置；不因空 feed 推断已降落。没有可核实记录仍显示暂无实时位置。

机场统一名称（IATA）。机型和分类使用来源原文，无分类则显示分类未提供；不从机型推断客货用途。延误为所选起飞或到达时间与计划时间的秒差除以 60，实际时间优先、缺失时使用预计时间，严格大于阈值告警。计算及证据保留原始精度，页面与历史动态统一显示最多一位小数并标明“约”；120 分 44 秒显示“约 120.7 分钟”。历史具体航班实例保留证据兼容。
