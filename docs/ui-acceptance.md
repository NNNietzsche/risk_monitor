# 界面验收

1. 固定交行页头只出现一次：船舶与航空资产风险监控 / 交通银行东京分行；右侧为最后刷新时间与状态。风险红色、数据待关注橙色、正常绿色、暂停/空列表灰色。
2. 首页压缩为操作、紧凑统计、船舶/航空两个跟踪面板；数据源名称在各自标题下，10 分钟自动采集提示在地图下。常用桌面视口首屏可见四个当前目标；小屏保持纵向滚动。
3. 创建船舶只选一种标识码，明确必填与选填，船名来自源、备注可选，无数据源/区域/船型手工选择。错误查询不留下空目标。
4. 船舶列表显示名称、IMO/MMSI/shipId、来源船型、出发港→到达港与状态；飞机显示注册号、机型、分类、航班、机场名称（代号）和状态。
5. 所有有效区域适用所有船，详情列出适用区域，地图绘制同一多边形。新增/删除后先显示待核查，不能沿用旧区域的有效结论。
6. 详情按状态、航线、时间、资产信息、历史位置和设置分组。缺失信息明确说明。备注编辑不改变来源名称。
7. 无演示入口、手动页面刷新、其他系统导航、LIVE 标签、公开新闻或 AI 区块。旧页面路径仅重定向。
8. 验证浏览器控制台、弹窗表单/错误、管理/详情、地图高亮和页头颜色；截图应来自实际运行页面。
