# 独立页面与接口

2026-09-30 起本系统独立运行，不依赖宿主系统的页面、导航或登录。

- `/` 直接返回监控首页；`/asset-risk.html` 与 `/demo.html` 重定向到 `/`。
- `/static/` 提供本地样式、脚本及地图资源；`/api/v1/` 提供页面数据与管理功能。
- `/api/v1/dashboard` 汇总监控目标、事件、公开信息与 AI 状态；`/api/v1/public/sources` 提供统一来源目录。
- 页面只读取现有记录；自动采集与船舶/航空刷新按钮负责查询外部数据。
- 线上由 Caddy 统一提供 HTTPS、Basic Auth 和反向代理。应用校验 Host 与修改请求的 Origin。
- 其他系统导航已移除。旧系统集成设想保留在 Git 历史，不再作为本阶段依赖。
